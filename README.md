# MyHAL 硬件抽象层  电赛控制题常用模块，算法驱动
##  高可移植性
    代码完全基于自命名bsp库，可在TI和ST等平台快速迁移，只需实现底层的bsp函数如电平读取，翻转等

## 高可读性
    提供了电赛控制题各种常用模块之间的驱动如电机，舵机，步进电机，蜂鸣器，按键，串口通信协议驱动等；
    各部分模块之间完全解耦，相互分离，互不影响，大大提高了代码的可读性

## 高可维护性
    自研任务流程驱动控制算法，为电赛控制题 任务流程控制 提供一体化解决方案，让任务流程更改，动态增删0成本

## 高拓展性
    模块可以随意拓展，如按键数量，电机数量等等，随意拓展至任意数量

## 高安全性
    数据之间高度解耦，为各种通信模块设计软件缓冲区，软件缓冲区自动维护，
    开发者只需要在有需求的时候对缓冲区读写即可，保证数据安全可靠的在不同文件之间转移，结构清晰
